### 一、"I" 开头的核心句型
1. **I'm + (动作 / 状态)**
    I'm going now. (我现在要走了)
2. **I'm a + (职业 / 身份)**
    I'm a teacher. (我是个老师)
3. **I'm good at + (动名词)**
    I'm good at playing basketball. (我擅长打篮球)
4. **I'm getting + (事物) + for (用途)**
    I'm getting sushi for lunch. (我午餐吃寿司)
5. **I'm trying to + (动词原形)**
    I'm trying to study for the test. (我在努力学习准备考试)
6. **I'm going to + (地点 / 动作)**
    I'm going to Thailand next week. (我下周要去泰国)
7. **I'm gonna + (动词原形)**
    I'm gonna make an appointment. (我要去预约)
8. **I'm in + (组织 / 团体)**
    I'm in a basketball club. (我在一个篮球俱乐部)
9. **I'm not used to + (名词 / 动名词)**
    I'm not used to cold weather. (我不习惯寒冷的天气)
10. **I'm not sure if + (从句)**
    I'm not sure if he is reliable. (我不能肯定他是否可靠)
11. **I'm looking forward to + (名词 / 动名词)**
    I'm looking forward to your birthday party. (我期待着你的生日聚会)
12. **I'm calling to + (动词原形)**
    I'm calling to book a room. (我打电话来订一个房间)
13. **I'm working on + (事物)**
    I'm working on my motorcycle. (我在修我的摩托车)
14. **I'm sorry to + (动词原形)**
    I'm sorry to tell you that I can't come. (很抱歉告诉你我不能来了)
15. **I'm thinking of + (动名词)**
    I'm thinking of going to Australia. (我在考虑去澳大利亚)
16. **I'm dying to + (动词原形)**
    I'm dying to finish work today. (我很想今天完成工作)
17. **I'm having a hard time + (动名词)**
    I'm having a hard time learning Spanish. (我学西班牙语很吃力)
18. **I'm afraid + (从句)**
    I'm afraid I can't come. (恐怕我不能来)
19. **I'm not satisfied with + (事物)**
    I'm not satisfied with my new hairstyle. (我对我的新发型不太满意)
20. **I have + (数量 / 事物)**
    I have two dogs. (我有两只狗)
21. **I used to + (动词原形)**
    I used to work at Apple. (我以前在苹果工作)
22. **I have to + (动词原形)**
    I have to clean my room today. (今天我得打扫房间)
23. **I have been + (动名词)**
    I have been working all day. (我工作了一整天)
24. **I wanna + (动词原形)**
    I wanna find a girlfriend. (我想找个女朋友)
25. **I would like to + (动词原形)**    
    I would like to see the menu. (我想看看菜单)
26. **I need to + (动词原形)**
    I need to see a doctor. (我需要看医生)
27. **I plan to + (动词原形)**
    I plan to go to sleep. (我要睡觉了)
28. **I didn't mean to + (动词原形)**
    I didn't mean to disturb you. (我不是故意打扰你的)
29. **I don't have time to + (动词原形)**
    I don't have time to chat on WeChat. (我没有时间在微信上聊天)
30. **I don't know how to + (动词原形)**
    I don't know how to use it. (我不知道怎么用)
31. **I don't like + (名词 / 动名词)**    
    I don't like video games. (我不喜欢电子游戏)
32. **I promise (that) + (从句)**
    I promise I won't leave without you. (我答应你不走我就不走)
33. **I want to + (动词原形)**
    I want to go shopping. (我想去购物)
34. **I'm busy + (动名词)**
    I'm busy talking with my boss. (我正忙着和老板谈话)
35. **I want to + (动词原形)**
    I want to talk to her. (我想和她谈谈)
36. **I want you to + (动词原形)**
    I want you to pick me up. (我想让你来接我)
37. **I have something to + (动词原形)**
    I have medicine to cure your headache. (我有药可以治你的头痛)
38. **I think (that) + (从句)**
    I think he should eat some breakfast. (我想他应该吃点早餐)
39. **I should have + (过去分词)**
    I should have bought a ticket. (我应该买张票的)
40. **I wish I could + (动词原形)**
    I wish I could attend the meeting. (我希望我能参加会议)
41. **I bet (that) + (从句)**
    I bet there will be a traffic jam. (我打赌会有交通堵塞)
42. **I can't wait to + (动词原形)**
    I can't wait to go to the beach. (我迫不及待地想去海滩)
43. **I don't know how to + (动词原形)**
    I don't know how to play mahjong. (我不会打麻将)
44. **I have got to + (动词原形)**
    I have got to be home by 9 PM. (我必须在晚上 9 点前回家)
45. **I wonder if + (从句)**
    I wonder if I can afford a BMW. (我想知道我是否买得起宝马)
46. **I would rather + (动词原形) + than + (动词原形)**
    I would rather take the subway than the bus. (我宁愿坐地铁也不愿意坐公共汽车)
47. **I have been + (动名词)**
    I have been thinking about changing jobs. (我一直在考虑换工作)
48. **I have decided to + (动词原形)**
    I have decided to... (我已经决定...)
49. **I heard (that) + (从句)**
    I heard he likes you. (我听说他喜欢你)
50. **I'm fed up with + (名词 / 动名词)**
    I'm fed up with this dish. (这道菜我已经吃腻了)
51. **I'll help you to + (动词原形)**
    
    I'll help you move tomorrow. (明天我帮你搬家)
52. **I'll let you know if + (从句)**
    
    I'll let you know if I'm free on Monday. (如果我星期一有空，我会告诉你的)
53. **I hope you will + (动词原形)**
    
    I hope you will call me when you arrive. (你到的时候给我打个电话)
54. **I don't want you to + (动词原形)**
    
    I don't want you to have an accident. (我不希望你发生意外)
55. **I would appreciate it if + (从句)**
    
    I would appreciate it if you could help me move. (如果你能帮我移动，我将不胜感激)
56. **May I + (动词原形)**
    
    May I come to the party? (我能来参加聚会吗？)

### 三、"We/They/He/She" 开头的句型

86. **We will + (动词原形) + as + (副词) + as possible**
    
    We will run as far as possible. (我们会尽可能地跑远)
87. **We went to + (地点) + to + (动词原形)**
    
    We went to the store to buy milk. (我们去商店买牛奶)
88. **We need + (事物) + to + (动词原形)**
    
    We need a place to live. (我们需要一个地方住)
89. **Let's not + (动词原形)**
    
    Let's not talk about this. (我们不谈这个)
90. **She is not only + (形容词) but also + (形容词)**
    
    She is not only beautiful but also intelligent. (她不仅漂亮而且聪明)
91. **He is as + (形容词) + as + (名词 / 代词)**
    
    He is as old as me. (他和我年龄一样大)
92. **He is so + (形容词) that + (从句)**
    
    He is so stubborn that I can't talk to him. (他很固执，我没法和他说话)
93. **As far as I know, + (从句)**
    
    As far as I know, it was canceled. (据我所知，它被取消了)
