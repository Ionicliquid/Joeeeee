## 场景一：从 App 上滑距离不够 → 松手回弹到 App (LAST_TASK)

**这是你问的场景 — 回弹动画不是 Transition 框架控制的！**

### 流程图

```
触摸事件 (SystemUI NavigationBar)
        │
        ▼
TouchInteractionService.onInputEvent()
        │
        ▼
OtherActivityInputConsumer.onMotionEvent()
        │
        ├─ ACTION_DOWN:
        │   startTouchTrackingForWindowAnimation()
        │   ├─ mHandlerFactory.newHandler()  → 创建 AbsSwipeUpHandler
        │   └─ mTaskAnimationManager.startRecentsAnimation()
        │       └─ SystemUiProxy.startRecentsActivity()
        │           └─ IRecentTasks.startRecentsTransition()  ← Binder 调用 → Shell
        │
        ├─ ACTION_MOVE:
        │   检查是否 passTouchSlop
        │   ├─ notifyGestureStarted()  → AbsSwipeUpHandler.onGestureStarted()
        │   └─ mInteractionHandler.updateDisplacement()  → onCurrentShiftUpdated()
        │       └─ applyScrollAndTransform()  更新窗口 Surface 位置
        │
        └─ ACTION_UP (滑动距离不够):
            finishTouchTracking()
            └─ mInteractionHandler.onGestureEnded()
                └─ handleNormalGestureEnd()
                    ├─ calculateEndTarget()  → LAST_TASK  ◄── ★关键判定★
                    │   └─ calculateEndTargetForNonFling():
                    │       velocity.y >= 0 || !mCanSlowSwipeGoHome → LAST_TASK
                    │
                    └─ animateGestureEnd() → animateToProgressInternal()
                        │
                        └─ ★ else 分支 (endTarget != HOME):

                            // ↑ 本地 ValueAnimator，把 mCurrentShift 从当前位置动画回0
                            //   NOT Shell Transition!
                            //   NOT RemoteTransition!

                                │
                                ▼
                            每帧回调: onCurrentShiftUpdated()

                                    └─ SurfaceControl.Transaction 提交到 WMS

                    动画完成
                        │
                        ▼
                    STATE_END_TARGET_ANIMATION_FINISHED
                        │
                        ▼
                    onSettledOnEndTarget() → case LAST_TASK:
                        │
                        ▼
                    resumeLastTask()
                        │
                        ▼
                    mRecentsAnimationController.finish(false, null)
                        └─ IRecentsAnimationController.finish(false, ...)

```

## 场景二：从 App 上滑足够 → 回桌面 (HOME)

### 流程图（关键差异）

```
... (前面流程与场景一相同) ...

ACTION_UP (滑动距离足够，速度向上):
    handleNormalGestureEnd()
    ├─ calculateEndTarget() → HOME
    │   └─ isFlingY && isSwipeUp → HOME
    │   或 calculateEndTargetForNonFling():
    │       velocity.y < 0 && mCanSlowSwipeGoHome → HOME
    │
    └─ animateToProgressInternal():
        └─ ★ HOME 分支 (line 1658):
            ├─ HomeAnimationFactory homeAnimFactory = createHomeAnimationFactory(...)
            │   ├─ LauncherHomeAnimationFactory / FloatingViewHomeAnimationFactory
            │   └─ 包含 Launcher 内容动画 (图标回位等)
            │
            ├─ RectFSpringAnim[] windowAnim = createWindowAnimationToHome(start, homeAnimFactory)
            │   └─ Spring 物理动画: App窗口 → 图标位置 (物理弹簧效果)
            │   └─ setupWindowAnimation(): addOnUpdateListener → 更新 SysUI flags
            │
            ├─ homeAnimFactory.playAtomicAnimation(velocity)  ← Launcher 内容动画
            │
            ├─ if (mHandOffAnimationToHome):
            │   handOffAnimation(velocityPxPerMs)
            │   └─ mRecentsAnimationController.handOffAnimation()
            │       └─ ★ Shell Transition 框架 ★
            │           (Long-lived return animation)
            │
            └─ windowAnim[i].start() → Spring 动画运行
                └─ 每帧更新: RectFSpringAnim.onUpdate()
                    └─ SurfaceTransaction 应用到 App 窗口

Spring 动画完成:
    ├─ mGestureState.setState(STATE_END_TARGET_ANIMATION_FINISHED)
    └─ onSettledOnEndTarget() → case HOME:
        └─ finishCurrentTransitionToHome()
            └─ finishRecentsControllerToHome()
                └─ mRecentsAnimationController.finishAnimationToHome()
                    └─ IRecentsAnimationController.finish(true, ...)

同时 QuickstepTransitionManager 可能参与:
    - WallpaperOpenLauncherAnimationRunner (RemoteAnimationFactory)
    - 当 Shell 触发 TRANSIT_CLOSE 时回调 Launcher
```

### 关键差异点

| 方面 | LAST_TASK (场景一) | HOME (场景二) |
|------|-------------------|---------------|
| 动画类型 | `ValueAnimator` on `mCurrentShift` | `RectFSpringAnim` (弹簧物理) |
| Launcher 内容动画 | ❌ 无 | ✅ `HomeAnimationFactory.playAtomicAnimation()` |
| Transition 框架 | ❌ 不涉及 | ⚠️ 部分涉及 (仅在 handOff 模式) |
| `QuickstepTransitionManager` | ❌ 无关 | ⚠️ `WallpaperOpenLauncherAnimationRunner` |
| 最终状态 | App 恢复前台 | Launcher NORMAL 状态 |

## 场景四-B：从 App 横向滑动距离不够 → 回弹到 App (LAST_TASK)

这是你刚问的场景 — 横向滑动了但没跨过页面边界。

### 核心判定逻辑

横向滑动距离不够时，判定链路分两阶段：

#### 第一阶段：RecentsView 的 Scroll Snap

在 `PagedView.onTouchEvent(ACTION_UP)` [PagedView.java:1460-1492](src/com/android/launcher3/PagedView.java#L1460-L1492)：

```java
// 不是 Fling + 不是 significant move → snapToDestination()
// snapToDestination() → mNextPage = getDestinationPage()
// getDestinationPage() 返回距离屏幕中心最近的页面
```

如果横向滚动没有超过页面中心（runningTask 仍然是最接近屏幕中心的页面）：
- `getDestinationPage()` → 返回 `runningTaskIndex`
- `mNextPage = runningTaskIndex`
- **页面 snap 回当前 Task**

#### 第二阶段：AbsSwipeUpHandler 的 EndTarget 判定

在 [AbsSwipeUpHandler.java:1335-1353](quickstep/src/com/android/quickstep/AbsSwipeUpHandler.java#L1335-L1353)：

```java
// isScrollingToNewTask():
//   mRecentsView.getNextPage() != mRecentsView.getRunningTaskIndex()
//   ↓ 由于第一阶段已 snap 回 runningTask 页面
//   ↓ getNextPage() == getRunningTaskIndex()
//   ↓ isScrollingToNewTask() == false!

// 然后走到：
if (isScrollingToNewTask && isFlingX) {
    return NEW_TASK;  // ← 不成立，因为 isScrollingToNewTask == false
} else if (mIsMotionPaused) {
    return RECENTS;   // ← 横向滑动一般不会触发 MotionPause
} else if (isScrollingToNewTask) {
    return NEW_TASK;  // ← 不成立
}
return velocity.y < 0 && mCanSlowSwipeGoHome ? HOME : LAST_TASK;
// ↑ 横向滑动时 velocity.y ≈ 0 → LAST_TASK
```

### 完整流程

```
用户在 App 内横向滑动导航栏（但距离不够跨到下一个 App）
        │
        ▼
OtherActivityInputConsumer.onMotionEvent(ACTION_MOVE)
        │
        ├─ 垂直方向: updateDisplacement() → mCurrentShift (窗口被"拖出")
        │
        └─ 水平方向: RecentsView 接收事件
            └─ RecentsView 横向滚动 → 但未跨过页面中心
```

```
ACTION_UP (松手):
        │
        ├─ RecentsView (PagedView.onTouchEvent):
        │   ├─ !isFling && !isSignificantMove
        │   ├─ snapToDestination()
        │   │   └─ getDestinationPage() → runningTaskIndex (当前App的页面)
        │   └─ mNextPage = runningTaskIndex  ← 页面 snap 回到当前 App
        │
        └─ AbsSwipeUpHandler.handleNormalGestureEnd():
            ├─ calculateEndTarget():
            │   ├─ isScrollingToNewTask() → false
            │   │   (因为 mNextPage == runningTaskIndex)
            │   ├─ isFlingX → false (速度不够)
            │   ├─ mIsMotionPaused → false
            │   └─ → LAST_TASK  ← 判定为回弹!
            │
            └─ animateToProgressInternal():
                └─ else 分支:
                    endShift = 0 (LAST_TASK.isLauncher == false)
                    AnimatorSet:
                    ├─ mCurrentShift 动画: 当前位置 → 0
                    │   └─ 窗口从被拖出的位置滑回原位
                    │
                    ├─ if (getNextPage() != getRunningTaskIndex()):
                    │   snapToPage(runningTaskIndex, duration)
                    │   └─ 但此条件不成立，因为已在第一阶段 snap 完成
                    │
                    └─ 动画完成 → resumeLastTask()
                        └─ RecentsAnimationController.finish(false)
                            └─ Shell 清理，App 恢复前台
```

### 与场景一（垂直方向距离不够）的对比

| 方面 | 场景一: 垂直不够 | 场景四-B: 横向不够 |
|------|-----------------|-------------------|
| 判定链路 | `calculateEndTargetForNonFling` → `velocity.y >= 0` → LAST_TASK | `isScrollingToNewTask()=false` → `velocity.y≈0` → LAST_TASK |
| RecentsView 滚动 | 无水平滚动 | 有水平滚动但 `snapToDestination()` 回到原页面 |
| `mNextPage` 值 | N/A（没有页面切换） | = `runningTaskIndex`（snap回当前页） |
| 回弹动画 | `ValueAnimator`: mCurrentShift → 0 | `ValueAnimator`: mCurrentShift → 0（相同） |
| Transition 框架 | ❌ | ❌ |

## 场景五：从 Launcher 桌面 → 上滑进入多任务 (Launcher NORMAL → OVERVIEW)

**此场景完全不使用 Shell RecentsAnimation！走的是 Launcher 内部状态切换。**

```
触摸事件 (在 Launcher Activity 内)
        │
        ▼
NoButtonNavbarToOverviewTouchController (继承链)
    PortraitStatesTouchController → AbstractStateChangeTouchController
        │
        ├─ SingleAxisSwipeDetector 手势检测
        │
        ├─ ACTION_MOVE:
        │   mCurrentAnimation.setProgress(displacement * mProgressMultiplier)
        │   └─ AnimatorPlaybackController: NORMAL ↔ OVERVIEW 过渡
        │       └─ 包括: Workspace 缩放、Hotseat 淡出、AllApps 淡入等
        │       └─ Launcher 内部 View 属性动画
        │
        └─ ACTION_UP:
            ├─ 计算最终状态 (NORMAL 或 OVERVIEW)
            │   基于进度阈值或 fling 速度
            │
            ├─ ★ ValueAnimator snap 到目标状态
            │   mCurrentAnimation.animateToValue(startProgress, endProgress)
            │   └─ Launcher 内部动画，不涉及 Shell
            │
            └─ 动画完成 → StateManager.goToState(targetState)
                └─ Launcher 状态机切换
```

**关键**: 这个流程**完全不经过**：
- ❌ `OtherActivityInputConsumer`
- ❌ `AbsSwipeUpHandler`
- ❌ `RecentsAnimationController`
- ❌ `SystemUiProxy.startRecentsActivity()`
- ❌ Shell Transition 框架

## 总结：Transition 框架参与情况

| 场景 | 判定 | 视觉动画 | Shell Transition? | RecentsAnimation? | QuickstepTransitionManager? |
|------|------|----------|-------------------|-------------------|----------------------------|
| 场景一: 垂直回弹 App | `LAST_TASK` | `ValueAnimator` | ❌ | ✅ start/finish | ❌ |
| 场景二: 回桌面 | `HOME` | `RectFSpringAnim` | ⚠️ handOff 时 | ✅ start/finish | ⚠️ WallpaperOpen |
| 场景三: 多任务 | `RECENTS` | `ValueAnimator` | ❌ | ✅ start/finish | ❌ |
| 场景四: 切换App | `NEW_TASK` | `ValueAnimator` | ❌ | ✅ start/finish | ❌ |
| 场景四-B: **横向回弹** | `LAST_TASK` | `ValueAnimator` | ❌ | ✅ start/finish | ❌ |
| 场景五: 桌面→多任务 | N/A | `AnimatorPlaybackController` | ❌ | ❌ | ❌ |
| 场景六: Back 手势 | N/A | `RectFSpringAnim` | ✅ 全程 | ❌ | ✅ WallpaperOpen |

### 你原问题的直接答案

**松手回到 Activity1 的 snap-back 动画：**
- **不是 Shell Transition 框架控制的**
- **不是 `QuickstepTransitionManager` 控制的**
- 是 `AbsSwipeUpHandler.animateToProgressInternal()` 中 **else 分支** 的一个**本地 `ValueAnimator`** 驱动的
- 它只是把 `mCurrentShift`（窗口偏移量）从当前值动画回 0，通过 `onCurrentShiftUpdated()` → `applyScrollAndTransform()` → `TaskViewSimulator` 每帧更新 Surface 位置
- 动画完成后调用 `RecentsAnimationController.finish(false)` 通知 Shell 做清理
