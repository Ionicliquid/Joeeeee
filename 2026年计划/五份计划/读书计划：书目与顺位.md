## 二、什么时候读

不排时间，只给两个建议窗口（都不占别的计划的窗口）：

| 窗口      | 说明                                    |
| ------- | ------------------------------------- |
| 周末午后    | 首选，想读就读，读多少算多少                        |
| 工作日午休   | 翻两页也行                                 |
| （不要去）睡前 | 23:15 到家后归睡眠；睡前手机已经在「插客厅」方案里了，别把书换成手机 |
