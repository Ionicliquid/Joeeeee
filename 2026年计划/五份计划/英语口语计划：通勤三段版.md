# 英语口语计划：通勤三段版（每周 4 集 · 20 周）

2026-09-26 改版：**每周 4 集** ｜ 20 周走完 80 集 ｜ 材料不动、不加时间

> 结构一句话：**周一至周四各开新 1 集；每集隔天三次接触（开新 → 跟读 → 复现）；周五补漏；周六 / 周日各 1h 收尾。**
> 用掉 11 / 15 个通勤槽位，剩 4 槽回炉——**不需要新增时间预算**。

## 零、中断重启协议（唯一必背）

| 情况 | 动作 |
| --- | --- |
| 漏了一天 | 下一个通勤照当天星期几的表走，**不补** |
| 漏了一周 | 从当周第 1 集继续，**不跳、不重设、不重排课表** |
| 断了很久，不知道从哪接 | 「回轨一步」：**打开手机放一遍 clip_loop12**，就算回到轨道 |
| 连续两晚睡不到 6 小时 | 英语当周降速到每周 3 集，睡眠优先 |

**判断标准是「断了之后多久回到轨道」，不是「连续多少天」。** 空周不算失败，作废课表才算。

## 二、每周怎么运转（槽位固定到星期，车厢里不做决定）

| 天 | 第一段 15′ | 第二段 40′ | 第三段 10′ |
| --- | --- | --- | --- |
| 周一 | 回炉 | **开新 A** | 回炉 |
| 周二 | 跟读 A | **开新 B** | 回炉 |
| 周三 | 跟读 B | **开新 C** | 复现 A |
| 周四 | 跟读 C | **开新 D** | 复现 B |
| 周五 | 跟读 D | 补漏 · 回炉 | 复现 C |
| 周六（1h） | 复现 D ＋ 输出日：A、B 自演 A 角 → 复述 → 录音 2 条 → 感觉分 1–5 | | |
| 周日（1h） | C、D 复述录音 1 条 ＋ 全周 4 集盲听速过 ＋ 记录一行 | | |

每集的三次接触都是**隔天**的：A = 周一开新 → 周二跟读 → 周三复现；D = 周四开新 → 周五跟读 → 周六复现。

四个槽位的定义（不变动，不用判断）：

| 槽位 | 干什么 | 完成标准 |
| --- | --- | --- |
| **开新**（40′） | 盲听 loop ×2 → 对稿 → 圈连读/生词 → 气声跟读 ×1 | 圈出 2–5 个点 |
| **跟读**（15′） | 气声逐句跟读 ×2，标卡点 | 标出 1–2 个卡点 |
| **复现**（10′） | loop ×1 盲听 ＋ 跟读 ×1 | 能跟上节奏 |
| **回炉** | 从学过的集里按学习顺序循环抽：10′/15′ 槽 = 1 集（loop ×1 ＋ 跟读 ×1）；40′ 槽 = 抽 2 集各盲听过一遍 | 不用挑，排到哪集算哪集 |
