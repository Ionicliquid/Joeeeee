# 减重每日记录

> **这份文件只有一个规则：每天早上写一行，写完就走。**
> 不要回填昨天。漏了就是漏了，下一行接着写，**中间空着几行完全没关系。**
> 空着几行不叫失败；空着几行之后再也不写了，才叫失败。

---

## 格式：一行 4 个字段，5 秒完成

| 字段   | 填什么                                                                        |
| ---- | -------------------------------------------------------------------------- |
| `晨重` | 起床排尿后、空腹、同一件衣服。只写数字                                                        |
| `动`  | `爬楼1趟(4)` / `爬楼2趟(3)` / `力量` / `休` / `最低`——1 趟 = 1→33 层到顶，电梯回 B1。括号里是**练完感觉 1–5 分**，练完当场随手打，别回头补 |
| `睡`  | 熄灯时间                                                                       |

**每格不要超过 6 个字。** 超过说明你在写日记，不是在打卡，那撑不过第三天。

### 最低版（加班 / 生病 / 累到不行那天）

**称重 + 写下这一行，就算完成。** `动` 格里写 `最低`，链条不断。

### 晚上的体重：只做备用，不做第二份成绩单

| 用途 | 规则 |
| --- | --- |
| **补行（唯一正式用途）** | 早上漏称时，晚上补一个数，写成 `105.4晚`——这一行照样算数，行数不丢 |
| 看着玩 | 想称就称，但不写进表格、不做任何决定的依据 |
| 红线 | **不因晚数高而加练或少吃。** 晚饭 + 水会把它垫高 0.5–1.5 kg——那不是「今天胖了」 |

7 日均重仍以晨数为主；偶尔带「晚」的补数照算，一两个点不影响趋势。

## 怎么数「行数」和「中断」

**只有 `晨重` 一格是必需的。** 只写了一个体重数字、其他三格全空，也算完整的一行。

| 情况 | 算一行？ | 算中断？ |
|---|---|---|
| 写了晨重，`动` 空着 | ✓ | ✗ |
| 那天没运动，`动` 写 `休` 或 `最低` | ✓ | ✗ **不算中断** |
| 加班到 1 点，整行没写 | ✗ | ✓ 中断 1 天 |
| 计划内的休息日，整行没写 | ✗ | ✓ **仍算中断** |

**唯一标准是那一行有没有字。** 一个数都没有 = 空行 = 中断。

> 为什么这么定：`休` 是计划里合法的格子（每周日本来就休息），所以「没运动」不能等于中断。
> **这张表测的是「你今天还认不认这个计划」，不是「你今天练没练」。**
> 后者由体重和周复盘负责，混进打卡里你就会开始数自己欠了多少。

- **行数** = 本周有几个格子写了字。不要求连续，≥ 5 即通过，空着的不回填
- **最长中断** = 本周最长的一段连续空行。拿这个数去查执行手册第一节的重启协议档位

### 示例：这周只爬了两次楼、只掉 0.6 kg，但它是成功的一周

| 日期     | 晨重    | 动       | 睡     | 判定           |
| ------ | ----- | ------- | ----- | ------------ |
| 0928 一 | 104.6 | 爬楼1趟(4) | 23:30 | 算            |
| 0929 二 | 104.4 |         |       | 算（只有体重）      |
| 0930 三 |       |         |       | **空 → 中断 1** |
| 1001 四 | 104.5 | 最低      | 00:10 | 算            |
| 1002 五 | 104.3 | 爬楼2趟(3) | 23:40 | 算            |
| 1003 六 | 104.1 | 休       | 23:20 | 算            |
| 1004 日 | 104.0 | 休       | 23:15 | 算            |

→ 行数 **6 / 5，通过** ｜ 最长中断 **1 天**，不用查重启协议，下周直接继续

**第一轮的主指标是这个 6，不是那个 0.6。**

## 怎么答「下周动哪一条规则」

**这一栏是刹车，不是油门。它的默认答案是「不改」。**

第一周、第二周，正确答案几乎一定就是 `不改`。写 `不改` 是合格回答，通常还是最优回答。

> 判定标准一句话：**改完之后，规则是变多了还是变少了？变多了就是答错了。**

### 按本周的数字选，不要按感觉选

| 本周情况 | 唯一允许的那一项改动 |
|---|---|
| 行数 < 5（没达标） | **只能减量，不能加量**：单次 2 趟 → 1 趟；或把通过线降到 4 行（仅限重建那一周） |
| 行数 ≥ 5，体重也没动 | 改**吃**的一项，只改一项（例：午餐米饭减到一半） |
| 行数 ≥ 5，体重在掉 | **不改。** 别去动一个正在工作的东西——这是最容易答错的一格 |
| 最长中断 > 3 天 | 不改计划。中断不在计划的控制范围内 → 查执行手册第一节重启协议 |

### 这四类答案直接划掉，不算数

| 划掉 | 为什么 |
|---|---|
| 「下次记得称重」「要提醒自己」「忍住不喝奶茶」「早点睡」 | 这是意志条款，不是改动。已经验证过 5 轮它无效 |
| 「下周改成 4 次」「每次 30 分钟」「加上力量」 | 升档有固定时间表（手册第二节），不由复盘决定。**"我觉得还有余力"不是升档理由** |
| 一次改两件 | 无法归因，等于没改 |
| 新增一项学习 / 运动目标 | 见手册第三节：本计划不承载别的事 |

### 一个被低估的合格答案：改「记录」本身

如果本周的中断是**忘了写**造成的，答案不是「记住要写」，而是动结构：

- 体重秤搬到牙刷旁边（刷牙 = 必须经过它）
- 闹钟标签从「6:20」改成「站到秤上」

这类改动是**做减法**的，所以合格。

### 对照

**合格**：`不改` ｜ `单次 2 趟→1 趟` ｜ `午餐米饭减到一半` ｜ `闹钟标签改成"站到秤上"` ｜ `秤搬到牙刷旁边`

**不合格**：`下周开始每天 40 分钟` ｜ `要更注意饮食` ｜ `早点睡` ｜ `少刷手机` ｜ `把学习和运动都排上`

**通过标准：体重掉 2 kg（105 → 103）就算达标。**

- 行数达标但体重没动 → 问题在吃的量，下一轮只调这一项，训练不变
- 体重掉了但行数没达标 → **本轮仍算成功**，下一轮重复第 1 周的量，不要升档
