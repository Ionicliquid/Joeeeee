# 周模板

> **用法**：周一早上复制本文件 → 命名 `2026-W39：混.md`（沿用你自己的命名法）。
> **全周只写两次：周一 3 行，周日 5 行。加起来 8 分钟。**
> 这张表只放**主线**。英语、读书、技术学习各自回自己的目录，不进这里（理由见 `五份计划/执行手册：五份计划.md` 第三节）。

---

## ⚠️ 先跑一遍五条检验，再填这张表

| # | 问 |
|---|---|
| 1 | 最差那天（第 21 天、感冒、6.5h 睡眠、22:00 下班）它还成立吗？ |
| 2 | 有没有哪一格要我当场判断"要不要"？ |
| 3 | 主指标是行为还是结果？ |
| 4 | 断掉之后回收动作写好了吗？ |
| 5 | **它比上一周更多还是更少？** |

第 5 条通不过就别写。**你历史上每一轮失败都是从"这周我要更狠"开始的。**

## 每周一填：本周主线

**只允许一条。** 写不满说明还没想清楚；写超了就删到一条。

判据：这一条必须**是行为，不是结果**。

```
主线：______________________________
本周唯一要动的规则（多数周的答案是"不改"）：____________
本周最大的崩点在哪一天、预案是什么：________________
```

参考写法：
- ✅ `减重：每周 3 次 × 1–2 趟，且每周 ≥5 行记录` ← 行为、可数、有预案
- ✅ `国庆 3 天的通过标准只有"称重 + 记一行"` ← 提前认输的地方先划出来
- ❌ `这周瘦 2 公斤` ← 结果指标，且有延迟，管不了任何行为
- ❌ `减肥 + 刷 20 题 leetcode + 读完《矛盾论》` ← 三域合表，W25/W38 两次都是这么全空的

## 每周日填：5 行复盘

```
行数 ____ / 5          → ≥5 就是成功（标准故意是 5 不是 7）
7 日均重 ____ kg        → 不看单日
最长中断 ____ 天        → >3 天去查重启协议，不改计划
本周只改一件事：______  → 默认答案：不改
下周主线第一条：______
```

想多写就随便写在下面，不限字数——**但复盘的正文不是打卡，写不出来也不代表失败。**

## 关于"每日 3 行日记"：先不要做

你问的是这个，我把它写出来，但**建议第 5 周之后再启用**。理由：

`每日记录.md` 已经占掉了你**唯一的一个每日动作**。再加一个每日 3 行 = 每天两个独立打卡 = 直接违反上面第 5 条检验。你的失败模式从来不是"记录不够丰富"，是"两个每日动作里有一个拖垮了另一个"。

**第一轮 4 周，每天只准碰一个文件：`每日记录.md` 的那一行。**

等 10/25 那个里程碑过了，再考虑加。那时候的格式是这样，三行封顶、不许加长：

```
### 1026 一
- 做了：
- 感：4
- 明天第一件事：
```

三行各司其职，别改设计：

| 行        | 作用          | 为什么必须有                                            |
| -------- | ----------- | ------------------------------------------------- |
| `做了`     | 一句事实，不评价    | 评价会引向愧疚，愧疚是这个循环的燃料                                |
| `感` 1–5  | 练完的感觉分      | **这是唯一能推翻"我练了也没区别"的证据**                           |
| `明天第一件事` | 提前替明天的自己做决定 | 自制力不是抵抗能力，是提前做好的决定的存量。晚上写这一格，等于在算力充足时给 6:20 那个你付款 |

第三行是三行里最值钱的，也是最容易被跳过的。**它跳过的那天早上，你会在"从该做了到开始了"那 30 秒里重新做一次决定——而那一刻你没有算力。**
